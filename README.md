# Ruva Salon

Premium React, Vite, TypeScript and Tailwind CSS website for Ruva Salon in Hiranandani Gardens, Powai, Mumbai.

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Notes

- Booking currently opens a contact modal because no verified online booking URL was supplied.
- Gallery and service imagery uses editorial placeholder photos and should be replaced with verified Ruva Salon assets before production launch.
- Social links are intentionally omitted until verified profiles are available.
